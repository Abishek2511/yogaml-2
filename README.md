## An AI-powered fitness application that uses computer vision and pose detection to analyse yoga and exercise performance in real time — scoring users based on accuracy and rewarding progress.
## Overview
YogaML is a machine learning-powered fitness application that acts as a virtual yoga and exercise coach. Using computer vision and joint angle analysis, it compares a user's live pose against the ideal reference pose for each exercise and provides real-time accuracy feedback and scoring.
Users can follow guided exercise and yoga videos, perform the movements on camera, and receive instant feedback on how accurately they're matching the target pose — with a gamified reward system to encourage consistency.
